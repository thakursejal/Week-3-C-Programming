# Week 3 – C Programming: Pointers & Strings

This repository contains my Week 3 internship work in C Programming.

The work focuses on pointer basics, pointer arithmetic, strings, string functions, and dynamic memory allocation using `malloc()` and `free()`.

## Topics Covered

- Pointer Basics
- Pointer Arithmetic
- Strings
- String Functions
- Dynamic Memory Allocation
- `malloc()`
- `free()`

## Assignments

### 1. Reverse a String Using Pointers

A C program that reverses a given string using pointers.

File: `assignments/01_reverse_string_pointers.c`

### 2. Count Vowels and Consonants

A C program that counts the number of vowels and consonants in a given string.

File: `assignments/02_vowels_consonants.c`

### 3. Swap Two Numbers Using Pointers

A C program that swaps two numbers using pointers and a user-defined function.

File: `assignments/03_swap_numbers_pointers.c`

### 4. Allocate Memory for an Array Using malloc

A C program that dynamically allocates memory for an array using `malloc()` and releases the memory using `free()`.

File: `assignments/04_malloc_array.c`

## Mini Project – Word Counter

A simple Word Counter program developed using pointers and strings.

The program accepts a sentence and counts the number of words in it.

### Features

- Accepts a sentence from the user
- Uses a string to store the input
- Uses a pointer to traverse the string
- Counts the words in the sentence
- Handles spaces, new lines, and tabs

File: `mini_project/word_counter.c`
